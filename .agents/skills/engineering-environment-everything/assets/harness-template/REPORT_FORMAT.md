# 보고 양식

회차 보고는 `loops/NN.md`에 남긴다. 실행기가 생성하는 `loops/NN.json`은 회차 완료와 복구를 위한 기계 기록이다. Markdown 보고가 늦게 작성돼도 JSON 기록을 근거로 보완한다.

## Loop NN — 사용자 현지 날짜

### 구현한 것

작업 ID, 바뀐 파일, 검증 ID, 실제 실행 명령과 관찰 결과를 적는다. 개별 검사 통과와 전체 완료를 구분한다.

### 미흡한 것

남은 작업, 실패·미검증·오류 항목과 필요한 조건을 적는다.

### 발견한 것과 결정

원인 분석, 실제 소비 측정값 또는 로그·시간 지표, 접근 변경과 가정을 적는다. 실측 토큰을 제공받지 못했으면 그 상태를 그대로 적는다.

### 다음 작업 또는 재개

자동 실행 중이면 다음 구현·검증 작업을 적고 계속한다. 완료되면 전체 검증 결과와 증거 경로를 제시한다. 중단 시 완료한 항목, 현재 작업, 막힌 이유, 남은 검증을 요약한다.

시간 초과 시 “A까지 구현했고 B를 구현·검증하다가 시간 제한에 도달했습니다. C부터 이어서 진행할까요? 다음 실행의 제한은 60분이며 원하는 시간으로 변경할 수 있습니다.”처럼 보고한다. 사용자 확인 전까지 시간 예산을 새로 시작하지 않는다.
