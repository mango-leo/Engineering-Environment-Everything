# 입력 파악

- 목표물과 전달 형식, 실행 대상, 완료 조건, 금칙, 숙련도 단서를 사용자 표현으로 정리한다. 기존 프로젝트라면 관련 문서와 설정에서 빈칸을 먼저 찾는다.
- 답에 따라 작업 목표, 검증 가능성, 호환성이나 주요 제약이 달라질 때만 한 번에 최대 세 가지를 묻는다. 전문 용어가 필요한 질문은 선택지와 `모르겠음`을 포함한다.
- 답이 없으면 유효한 성공 증거나 금칙을 정할 수 없는 경우에는 질문에 대한 답을 받은 뒤 프로파일을 작성한다. 합리적인 조건부 초안을 만들 수 있다면 미정 사항을 표시하고 프로파일 검토 때 함께 확인한다. 합성 중 생긴 질문도 최대 세 개 안에 포함한다.
- 사용자가 모르는 정보는 작업을 되돌리기 쉬운 기본값으로 정하고 가정으로 표시한다. 실제 장비나 외부 접근 권한처럼 확인이 필요한 조건은 미정으로 남긴다.
- 명시한 요구와 추론을 구분해 프로파일에 전달한다. 프로파일 검토 뒤 명세를 만들 때도 가정이 보이게 유지한다.
